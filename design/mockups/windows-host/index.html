Kagaz · a Windows computer shared while its person goes on using it

Drawn with the app's own stylesheets: the shared computer in the Windows look, the device connecting in the Ubuntu look. Devices and names are made up; the "screens" are coloured stand-ins.

  • Two Kagaz, two roles. Kagaz on the office laptop shares its screen; Kagaz here connects to it and shows it in a session window, as with any computer today: picture, sound, clipboard, files.
  • Both people use the same desktop. Nobody is signed out. The device connecting can watch only or use the mouse and keys; the person at the laptop can switch it to watch only, or end it, at any time.
  • Every choice is a setting (your answers of 18 November): ask each time or connect with the PIN, start with Windows (off unless turned on), three ways for the sign-in screen and administrator prompts, watch or control from either end.
  • Straight from one device to the other, over the local network or Tailscale; nothing passes through anyone else's servers.
